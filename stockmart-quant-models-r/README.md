# stockmart-quant-models-r 🧮

Quantitative pricing models — Black-Scholes, Greeks, CAPM, factor models.

## Features
- Black-Scholes option pricing (calls & puts)
- Greeks: Delta, Gamma, Theta, Vega, Rho
- CAPM beta & expected return
- Fama-French 3-factor model simulation

## Stack
R 4.3 · stats · dplyr
