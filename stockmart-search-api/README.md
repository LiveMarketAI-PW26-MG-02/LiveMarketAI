# stockmart-search-api 🔍

Ecommerce-style product search for stocks — full-text symbol/name lookup, filters, facets.

## Features
- Symbol + company name search
- Filter by sector, exchange, market cap tier
- Autocomplete / suggest
- "Related stocks" (like ecommerce recommendations)

## Stack
Python 3.11 · FastAPI · rapidfuzz (fuzzy match)
