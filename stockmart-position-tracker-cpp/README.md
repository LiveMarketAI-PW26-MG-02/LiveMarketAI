# stockmart-position-tracker-cpp ⚡

Real-time position tracking — inventory management for a stock brokerage.

## Features
- Per-account position ledger
- Real-time P&L mark-to-market
- Short position handling
- Aggregated exposure report

## Stack
C++17 · CMake

## Build
```bash
cmake -B build && cmake --build build
./build/position_tracker
```
